# Contributing to `@innovatorved/code-lab`

Thank you for contributing to `@innovatorved/code-lab`! This document covers the local development workflow, architecture invariants, and verification gates.

## Prerequisites

- **Bun** `>= 1.1` (used for building bundles and running the primary test/typecheck scripts)
- **Node.js** `>= 20` (CI verifies all suites across Node 20, 22, and 24)
- **Playwright Chromium** (optional locally, required for browser E2E tests: `bunx playwright install chromium`)

## Quick Start

```bash
# 1. Install dependencies
bun install

# 2. Build all distribution bundles into dist/
bun run build

# 3. Run static analysis gates
bun run lint
bun run typecheck
bun run typecheck:strict

# 4. Run the 32 automated test suites under Bun and Node
bun run tests/run-all.js
node tests/run-all.js

# 5. Run real Chromium E2E tests
bun run test:browser
```

## Development Invariants

1. **Bundle-First Testing (`dist/` is untracked)**:
   - `dist/` is generated by `bun run build` (`tools/bundle.js`) and must never be committed to git (`tests/test-untracked-dist.js` enforces this).
   - Every test suite loads from `dist/` via `tests/helpers/load.js` rather than importing raw TypeScript from `src/`. Always run `bun run build` after editing `src/*` before running tests.
2. **Dual-Runtime Portability (Bun + Node 20/22/24)**:
   - Test suites in `tests/` must run under plain `node` without Bun-only APIs or custom TypeScript loaders.
3. **Zero Empty `catch` Blocks**:
   - `bun run lint` (`tools/lint.js`) fails if any `catch` block in `src/*.ts` has an empty or comment-only body. Route unexpected exceptions through the structured logger (`src/logger.ts`) or handle/rethrow explicitly.
4. **Strict TypeScript Ratchet (`tsconfig.strict.json`)**:
   - New leaf modules in `src/` must compile cleanly under `tsconfig.strict.json` (`strict: true`, `noImplicitAny: true`, `strictNullChecks: true`, `noUncheckedIndexedAccess: true`) and never use `@ts-nocheck`.
5. **Single Source of Truth for Version & Counts**:
   - `package.json.version` is injected into `dist/*` by `tools/bundle.js`. Do not hardcode stale version strings in `src/` or documentation (`tests/test-version-sync.js` verifies version and capability count sync).

## Pull Request Checklist

- [ ] `bun run build` succeeds and `bun run pack:check` passes.
- [ ] `bun run lint`, `bun run typecheck`, and `bun run typecheck:strict` pass with zero errors.
- [ ] `bun run tests/run-all.js` and `node tests/run-all.js` pass all 32 suites.
- [ ] `bun run test:browser` passes all Playwright Chromium specs.
- [ ] New features or bug fixes include regression tests in `tests/`.
